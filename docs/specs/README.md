Regras:
- A spec descreve **o quê** e **por quê**. O **como** fica no código e, se for polêmico, num ADR.
- Critérios de aceite são verificáveis (checkbox). Itens que dependem da TV ficam explícitos como "manual".
- O que não se sabe sobre a TV vai em "Questões em aberto" com ⚠️. Não chute.
